# SDK Installation

Install the SDK:

    npm install @11ai/execution-governance

To gate an existing MCP server, install the proxy as well:

    npm install @11ai/mcp-gate

## Signing keys

The gate signs every decision receipt. Provide a stable signing key through the
environment rather than hardcoding it:

    EG_SIGNING_KEY=your_signing_key_here

If no signing key is provided the gate generates an ephemeral one and warns.
Receipts signed with an ephemeral key cannot be verified across restarts.

Do not hardcode secrets, API keys, certificates, or credentials in source code.
